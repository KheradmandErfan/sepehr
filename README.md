## معرفی

«سپهر» یک وب‌اپ تک‌صفحه‌ای برای خواندن شعر شاعران پارسی‌گوست. «سپهر، گنجینه بی‌کران اشعار پارسی». خود سایت ایستا است و روی GitHub Pages اجرا می‌شود. شعرها، حساب کاربری، مشاعره و جستجوی معنایی از راه یک Worker روی Cloudflare در دسترس‌اند و نشانی آن در `config.js` تنظیم می‌شود.

## ویژگی‌ها

**خواندن**
- فهرست شاعران، دسته‌ها و کتاب‌ها و صفحهٔ هر شعر با چند خط فارسی (نستعلیق و دیگر خط‌ها)
- تغییر اندازهٔ متن، شماره‌گذاری ابیات، نمایش معنی ابیات، رونوشت و اشتراک‌گذاری
- نوار ابزار چسبان، لغزش خودکار به خط در حال خوانش و ذخیرهٔ برون‌خط
- قفسهٔ کتاب‌ها با کتاب سه‌بعدی و ورق‌زدن واقعی صفحه‌ها

**جستجو**
- جستجو در متن همهٔ شعرها (عبارت دقیق یا نزدیک)، همراه با پالایه‌هایی مثل قالب و وزن
- جستجوی عنوان شعرها در آثار یک شاعر
- یافتن شاعران، کتاب‌ها و شاعران هر سده (مثلاً «قرن هشتم»)
- جستجوی معنایی (نیازمند حساب کاربری و Worker)

**ابزارها و سرگرمی**
- فال حافظ (با صفحهٔ انتظار)، محاسبه‌گر ابجد، مشاعره با دیگر کاربران
- نقشهٔ زادگاه سخنوران، با ورودی کرهٔ زمین چرخان در صفحهٔ اصلی
- دلخواه‌ها، حاشیه‌نویسی (حاشیه‌های سایت و حاشیه‌های بیرونی یک‌جا) و تاریخچه

**ظاهر و تجربهٔ کاربری**
- پوستهٔ روشن و تیرهٔ فیروزه‌ای اصفهانی (با گزینهٔ «مطابق سیستم»)
- گوشه‌های گرد و انیمیشن‌های نرم در همهٔ بخش‌ها (در صورت فعال‌بودن «کاهش حرکت» دستگاه، خاموش می‌شوند)
- انتخاب نحوهٔ نمایش دکمه‌ها از بخش تنظیمات: آیکون، آیکون و متن، یا فقط متن
- برنامک وب پیش‌رونده (PWA): قابل نصب روی گوشی، با کار برون‌خط برای شعرهای دیده‌شده

## فناوری‌ها

| بخش | ابزار |
|---|---|
| رابط کاربری | یک فایل HTML با CSS و جاوااسکریپت خالص، بدون کتابخانه و بدون مرحلهٔ ساخت |
| دادهٔ شعر | Worker کلودفلر (نشانی در `config.js`) |
| میزبانی | GitHub Pages |
| پشتیبان (اختیاری) | Cloudflare Workers + KV (+ Workers AI) |
| برون‌خط | Service Worker و Web App Manifest |

## ساختار پروژه

```
.
├── index.html                # کل برنامه (HTML + CSS + JS)
├── config.js                 # تنظیم نشانی Worker
├── robots.txt                # راهنمای خزندهٔ موتورهای جستجو
├── sitemap.xml               # نقشهٔ سایت برای گوگل
├── sw.js                     # Service Worker (کش پوسته و شعرها)
├── manifest.webmanifest      # مشخصات برنامک وب
├── worker.js                 # پشتیبان Cloudflare (اختیاری؛ در Pages بارگذاری نمی‌شود)
├── icon.svg                  # آیکون سایت (نشانگر برگه)
├── icon-192.png
├── icon-512.png
├── icon-maskable-512.png     # آیکون سازگار با قالب‌های گرد اندروید
├── apple-touch-icon.png      # آیکون صفحهٔ اصلی آیفون و آیپد
└── README.md
```

## اجرا روی رایانهٔ خودتان

Service Worker فقط روی `http(s)` کار می‌کند، پس فایل را با یک سرور ساده باز کنید:

```bash
python3 -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

## استقرار

راهنمای گام‌به‌گام ساخت مخزن، روشن‌کردن GitHub Pages و راه‌اندازی Worker در فایل `README-SETUP.md` آمده است.

## سئو

- `index.html` عنوان، توضیح، کلیدواژه، Open Graph، Twitter Card و داده‌های ساختاریافتهٔ JSON-LD دارد.
- `robots.txt` و `sitemap.xml` را پیش از انتشار با نشانی واقعی سایت (به‌جای `USERNAME`) به‌روز کنید و سایت‌مپ را در Google Search Console ثبت کنید.

## ظاهر: تم اصفهانی

- **فیروزه‌ای کاشی** رنگ اصلی است، **لاجورد** و **زر** تکمیلش می‌کنند و **کرم آجری** زمینهٔ پوستهٔ روشن است.
- زمینهٔ سایت کاشی‌کاری ستارهٔ هشت‌پر (خاتم) است که بسیار آرام می‌لغزد.
- سربرگ و منوی پایین کپسولی‌اند و بالای صفحهٔ شعر شکل طاق دارد.

رنگ‌ها و گردی‌ها با متغیرهای CSS در ابتدای لایهٔ «تم اصفهان صفوی» (داخل `<style>`) تعریف شده‌اند و به‌سادگی تغییر می‌کنند.

## سپاس

- سپاس از همهٔ گردآورندگان و پاسدارانِ متن شعر پارسی.
- خط‌های فارسی از Google Fonts و مجموعه‌های آزاد بارگذاری می‌شوند.
